# Điều kiện qua step tiếp theo

Step `DEMO-00` chỉ được coi là hoàn thành khi:

1. File `DEMO_SCOPE_LOCK.md` đã nằm đúng vị trí trong thư mục `/demo/`.
2. Nội dung đọc dễ hiểu, rõ ràng các nguyên tắc về Mock/Demo-only.
3. Có mục Clean Demo Foundation: mock-only ở tính năng nhưng cấu trúc code phải tái sử dụng được cho project chính (không throwaway).
4. Không có bất kỳ dòng code frontend/backend nào được sinh ra ngoài phạm vi tài liệu.
5. Đã commit thành công với nội dung đúng chuẩn `docs: add NovaWay demo scope and git strategy`.
