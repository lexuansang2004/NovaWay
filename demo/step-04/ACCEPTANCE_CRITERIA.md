# Điều kiện qua step tiếp theo

Step `DEMO-04` chỉ được coi là hoàn thành khi:

1. Kiến trúc React Router đã được setup vững chắc (phân tách rõ Public Routes và Protected Routes).
2. App Shell hiển thị chuẩn xác, UI sang trọng đúng chuẩn bộ thư viện Tailwind + shadcn/ui.
3. Luồng đăng xuất và kiểm tra quyền truy cập (Auth Guard) hoạt động hoàn hảo 100%.
4. Đã commit code đúng chuẩn.
