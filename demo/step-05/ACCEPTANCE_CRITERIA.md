# Điều kiện qua step tiếp theo

Step `DEMO-05` chỉ được coi là hoàn thành khi:

1. Trải nghiệm Vertical Accordion phải thật sự mượt mà (cuộn tự động, làm mờ/sáng các vùng hợp lý).
2. Flow liên kết dữ liệu không bị đứt gãy (chọn Mode -> lọc Xe -> FaceID).
3. Đảm bảo triệt để tư duy SPA (Single Page Application): Transition sang Map Cockpit mà không cần reload trang hay điều hướng đi URL khác.
4. Đã commit code đúng chuẩn.
