# Điều kiện qua step tiếp theo

Step `DEMO-10` chỉ được coi là hoàn thành khi:

1. Hệ thống AR HUD kích hoạt hoàn toàn tự động dựa trên khoảng cách.
2. Hiệu ứng Visual (Viền đỏ, lưới AR) mượt mà, tạo cảm giác công nghệ.
3. API giọng nói (Web Speech API) chạy ổn định, cảnh báo song ngữ chuẩn xác, tự động ngắt đúng lúc khi đã qua khỏi vùng nguy hiểm.
4. Ghi nhận dữ liệu (Audit Log) không bị spam (chỉ lưu 1 log / 1 vật cản / 1 lượt quét).
5. Đã commit code đúng chuẩn.
