# Điều kiện qua step tiếp theo

Step `DEMO-02` chỉ được coi là hoàn thành khi:

1. Trải nghiệm login mượt mà, không bị giật lag khi chuyển đổi giữa Form và Loading Screen.
2. Màn hình Loading VR Scanner hiển thị cực kỳ đẹp mắt, ra chất sci-fi tương lai, đúng như mô tả chi tiết của PO.
3. Component Loading có thể dễ dàng được import và tái sử dụng ở các màn hình khác bằng cách gọi thẻ `<VRScannerLoading />` hoặc hàm bật/tắt toàn cục.
4. Trạng thái Auth lưu trữ bền vững trong Browser.
5. Commit code đúng chuẩn.
