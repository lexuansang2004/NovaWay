# Điều kiện qua step tiếp theo

Step `DEMO-11` chỉ được coi là hoàn thành khi:

1. Kiến trúc State (Zustand/Context) được cấu trúc lại chuẩn xác để bảo vệ tiến trình (Lifecycle) của chuyến đi qua các routes khác nhau.
2. Component Mini-player (Floating Widget) mượt mà và hoạt động đúng logic ẩn/hiện.
3. Thuật toán trừ điểm Safety Score chạy đúng công thức.
4. UI Dashboard tổng kết có vòng tròn điểm số đẹp mắt, sử dụng SVG nhẹ nhàng.
5. Đã commit code đúng chuẩn.
