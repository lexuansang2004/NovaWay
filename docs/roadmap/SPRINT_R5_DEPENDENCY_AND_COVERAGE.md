# NovaWay — Sprint R5: Dependency Hygiene & Coverage of Real Runtime Code

> Sprint thứ năm, sau `Sprint R4: Codebase Hardening` (`docs/roadmap/SPRINT_R4_HARDENING.md`, đóng 7/7 mục 07/2026). R4 đã dọn hết phát hiện UX/bảo mật nhỏ trong code tự viết, nên R5 chuyển trọng tâm sang hai chỗ R4 cố ý chưa đụng: **cây dependency** (R4 để ngoài phạm vi vì cần major upgrade) và **những file code chạy thật nhưng chưa từng có test** ở tầng còn lại (error filter, HTTP client của web/mobile). ## 1. Sprint Goal

Giảm bề mặt lỗ hổng dependency bằng những thay đổi **đo được** (không nâng cấp lấy lệ), và phủ test cho code networking/contract đang chạy thật ở cả 3 app. Không thêm tính năng sản phẩm mới.
