# NovaWay — Sprint R5: Dependency Hygiene & Coverage of Real Runtime Code

> Sprint thứ năm, sau `Sprint R4: Codebase Hardening` (`docs/roadmap/SPRINT_R4_HARDENING.md`, đóng 7/7 mục 07/2026). R4 đã dọn hết phát hiện UX/bảo mật nhỏ trong code tự viết, nên R5 chuyển trọng tâm sang hai chỗ R4 cố ý chưa đụng: **cây dependency** (R4 để ngoài phạm vi vì cần major upgrade) và **những file code chạy thật nhưng chưa từng có test** ở tầng còn lại (error filter, HTTP client của web/mobile). Cùng phương pháp R4: audit thật trước, mỗi mục đều có file + dòng + số đo, không có mục nào dựa trên suy đoán.

## 1. Sprint Goal

Giảm bề mặt lỗ hổng dependency bằng những thay đổi **đo được** (không nâng cấp lấy lệ), và phủ test cho code networking/contract đang chạy thật ở cả 3 app. Không thêm tính năng sản phẩm mới.

## 2. Phương pháp audit (đã chạy thật trước khi viết backlog này, 27/07/2026)

- `pnpm audit --json` toàn workspace, rồi truy `findings[].paths` từng advisory để phân loại **reachable từ runtime** hay chỉ nằm dưới một devDependency/build tool. Kết quả tổng: **30 advisory** — 1 critical, 15 high, 13 moderate, 1 low.
- `pnpm outdated -r` + `flutter pub outdated`.
- Đối chiếu `docs/API_CONTRACT.md` với route thật (`grep @Controller/@Get/@Post/...`): **khớp 1:1, không có drift** — không có mục backlog nào từ hướng này.
- Grep `console.log`/`print`/`TODO`/`FIXME` trên code đã commit: chỉ còn `console.log` trong script CLI (`benchmark-gps-dedup.js`, `write-version.mjs` — cố ý) và một `console.warn` cảnh báo thiếu config hợp lệ (`TripMap.tsx:34`). Sạch, trừ đúng một TODO có hậu quả thật → R5-1.
- Liệt kê file source **không có** file test tương ứng ở cả 3 app, rồi đọc từng file để loại bỏ những file chỉ là interface/DTO/module wiring.

## 3. Ngoài phạm vi (Out of Scope) — kèm lý do đã kiểm chứng

- **Advisory `react-router` (high, "RSC Mode CSRF Bypass")** — **không reachable**. Đã kiểm tra thật: `apps/web/src/main.tsx` dùng `BrowserRouter` khai báo thuần, không `createBrowserRouter`/`RouterProvider`, không RSC, không server-side action nào (grep `createBrowserRouter|RouterProvider|unstable_|RSC` trên `apps/web/src` → 0 kết quả). Advisory chỉ patched ở `>=8.3.0`, tức phải nâng major v7 → v8 để dọn một lỗ hổng ở chế độ dự án không dùng — không đáng, ghi nhận lại đây để lần audit sau khỏi kết luận lại từ đầu.
- **`typeorm` 0.3.x → 1.1.0** — giữ nguyên quyết định R4: major, rủi ro breaking change lớn, cần TDR riêng.
- **Advisory còn lại chỉ dọn được bằng `typeorm` major hoặc NestJS v11** — không tách thành mục riêng, đã gộp vào R5-4.
- **R3-4 (UI capture khuôn mặt thật trên mobile)** — vẫn hoãn, chưa có thiết bị Android/iOS thật. Không đổi so với R3/R4.
- **Nâng version vá nhỏ hàng loạt** (`react` 19.2.7→19.2.8, `radix-ui`, `lucide-react`, `recharts`, `@playwright/test`, `oxlint`, `@typescript-eslint/*`, `ts-jest`…) — không advisory nào dính tới chúng, nâng chỉ để nâng thì không có giá trị đo được và làm loãng diff review.
